# NASM CPT (7th Edition) — Complete Exam Study Guide
### Everything weighted to one goal: passing the test

**Source:** NASM Essentials of Personal Fitness Training, 7th Edition + Fitness Mentors free NASM study guide + your cheatsheet notes + current (2025–2026) NASM CPT exam blueprint.
**Scope:** Whole certification, organized the way the exam actually weights it — not chapter by chapter.

> **Why this guide is built this way:** The NASM exam is not evenly distributed. Two domains — **Exercise Technique (24%)** and **Program Design (20%)** — are 44% of your score. The whole test is built around one thing: **the OPT model**. If you know the OPT model cold (the 5 phases and the acute variables for each) and the overhead squat assessment (which muscles are tight vs. weak), you have covered the largest, most reliably tested chunk of the exam. This guide front-loads exactly that. Everything else is supporting cast.

# PART 1 — KEY TERMS
### Split by topic, source order

## 1A. The OPT Model & Program Design

| Term | Definition |
|---|---|
| **OPT Model** | Optimum Performance Training model — NASM's system. **3 levels**, **5 phases**. |
| **Level: Stabilization** | Goal = muscular **endurance** and joint stability. Contains Phase 1. |
| **Level: Strength** | Goal = build force / muscle. Contains Phases 2, 3, 4. |
| **Level: Power** | Goal = rate of force production (speed × strength). Contains Phase 5. |
| **Phase 1 — Stabilization Endurance** | Endurance + stability. Unstable-but-controllable surfaces. |
| **Phase 2 — Strength Endurance** | Superset a strength exercise with a stabilization exercise. |
| **Phase 3 — Muscular Development (Hypertrophy)** | Maximal muscle growth. High volume. |
| **Phase 4 — Maximal Strength** | Highest loads, lowest reps. Max prime-mover strength. |
| **Phase 5 — Power** | Heavy strength move paired with an explosive/light-fast move. |
| **Acute variables** | The specifics you adjust: reps, sets, intensity, tempo, rest, volume, frequency, duration, exercise selection. |
| **Periodization** | Dividing a training program into progressive phases/cycles. |

## 1B. Anatomy & Muscle Physiology

| Term | Definition |
|---|---|
| **Neuron** | Nerve cell. 3 parts: **cell body, axon, dendrites.** |
| **Dendrites** | Receive incoming signals (bring info TO the cell body). |
| **Axon** | Carries the signal AWAY from the cell body. |
| **Muscle spindle** | Senses **change in muscle LENGTH** → triggers **stretch reflex** → causes contraction (protects against overstretch). |
| **Golgi tendon organ (GTO)** | Senses **change in muscle TENSION** → causes **relaxation** (protects against too much force). Located at the musculotendinous junction. |
| **Epimysium / Perimysium / Endomysium** | Muscle connective-tissue layers, outer → inner (endomysium is deepest, wraps each fiber). |
| **Sarcomere** | The smallest contractile unit of muscle. |
| **Type I (slow-twitch) fiber** | More oxygen, smaller, less force, slow to fatigue. Endurance/postural. |
| **Type II (fast-twitch) fiber** | Less oxygen, larger, more force, fast to fatigue. Power/strength. |
| **Wolff's Law** | **BONE** remodels along lines of stress. (Bone = "W" for Wolff.) |
| **Davis's Law** | **SOFT TISSUE** models along lines of stress. (Corollary to Wolff's.) |
| **Roll / Slide / Spin** | The 3 arthrokinematic (joint) motions. |

## 1C. Cardiorespiratory & Energy Systems

| Term | Definition |
|---|---|
| **ATP-PC system** | ~10–15 sec, fastest, **no oxygen**, high intensity, short duration. |
| **Glycolysis** | ~30–50 sec, uses **carbohydrates**, medium duration, produces lactate. |
| **Oxidative (aerobic) system** | Slow, uses oxygen, long duration. Fuels fat + carbs. |
| **3 stages of the oxidative system** | Aerobic glycolysis → **Krebs cycle** → **electron transport chain (ETC)**. |
| **Respiratory Quotient (RQ)** | Ratio of CO₂ produced to O₂ used. **RQ 0.70 = 100% fat; RQ 1.0 = 100% carbs.** |
| **Blood vessels (order out to back)** | Arteries → arterioles → **capillaries** → venules → veins. |
| **Radial pulse** | Wrist pulse — the recommended site for self-measurement. |

## 1D. Assessment & Posture

| Term | Definition |
|---|---|
| **Overhead squat assessment (OHSA)** | The signature dynamic postural assessment. Reveals tight (overactive) and weak (underactive) muscles. |
| **Pronation distortion syndrome** | Feet/ankle/knee distortion (flat feet, knees in). |
| **Lower crossed syndrome** | Anterior pelvic tilt — tight hip flexors/low back, weak abs/glutes. |
| **Upper crossed syndrome** | Forward head + rounded shoulders — tight chest/upper traps, weak deep neck flexors/lower traps. |
| **Overactive / tight** | Muscle that is short and pulling the joint out of alignment. |
| **Underactive / weak** | Muscle that is lengthened/inhibited and not doing its job. |
| **Cumulative injury cycle** | Trauma → inflammation → spasm → adhesions → altered neuromuscular control → muscle imbalance → repeat. |

# PART 2 — MAIN CONCEPTS

## 2.1 The OPT Model — the spine of the whole exam

**Simple:** NASM builds every client program in a ladder. First you teach the body to be **stable and have endurance**, then you build **strength/muscle**, then you build **explosive power**. You don't skip rungs — a beginner always starts at Phase 1.

**Technical:** 3 levels (Stabilization, Strength, Power) divided into 5 phases.

```
LEVEL 1: STABILIZATION      LEVEL 2: STRENGTH               LEVEL 3: POWER
 └─ Phase 1                  ├─ Phase 2 Strength Endurance   └─ Phase 5 Power
    Stabilization Endurance  ├─ Phase 3 Hypertrophy
                             └─ Phase 4 Maximal Strength
```

> **CRITICAL:** Cardiorespiratory training exists in **all three levels** (Stage I, II, III cardio). Every level has a cardio component — do not think cardio only lives in one phase.

**The acute variables table — memorize this cold. This is the single most tested table on the exam:**

| Phase | Reps | Sets | Intensity (%1RM) | Tempo | Rest |
|---|---|---|---|---|---|
| **1 — Stabilization Endurance** | 12–20 | 1–3 | 50–70% | **Slow (4/2/1)** | 0–90 sec |
| **2 — Strength Endurance** | 8–12 | 2–4 | 70–80% | Moderate (2/0/2) + slow on stab. | 0–60 sec |
| **3 — Hypertrophy** | 6–12 | 3–5 | 75–85% | Moderate (2/0/2) | 0–60 sec |
| **4 — Maximal Strength** | 1–5 | 4–6 | 85–100% | **Fast/explosive (X/X/X)** | **3–5 min** |
| **5 — Power** | 1–10 | 3–6 | 30–45% (or ~10% BW / up to 45%) | **Fast/explosive** | 3–5 min |

*(Tempo notation = eccentric/isometric/concentric seconds. 4/2/1 = 4 sec lowering, 2 sec pause, 1 sec lifting.)*

**Memory anchor for reps:** As you climb the phases toward strength, **reps go DOWN and intensity goes UP**. Endurance = light + many reps + long tempo. Max strength = heavy + few reps + fast. Power splits into two: a heavy move AND a fast light move.

## 2.2 Muscle fibers — the reversible pair

**Simple:** Slow-twitch = marathon muscle. Fast-twitch = sprint muscle.

| | **Type I (Slow-twitch)** | **Type II (Fast-twitch)** |
|---|---|---|
| Oxygen use | **More** (more mitochondria, more capillaries) | Less |
| Size | Smaller | **Larger** |
| Force | Less | **More** |
| Fatigue | Slow to fatigue | Fast to fatigue |
| Color | Red (more myoglobin) | White |
| Job | Posture, endurance | Power, sprinting |

## 2.3 Muscle spindle vs. Golgi tendon organ — the classic trap pair

**Simple:** The spindle protects you from stretching too far. The GTO protects you from pulling too hard.

| | **Muscle spindle** | **Golgi tendon organ (GTO)** |
|---|---|---|
| Senses | Change in **LENGTH** (and rate) | Change in **TENSION** |
| Response | **Contracts** the muscle (stretch reflex) | **Relaxes** the muscle (autogenic inhibition) |
| Location | Within the muscle belly (parallel to fibers) | At the musculotendinous junction |
| Used in | Why fast/ballistic stretching is risky | Why holding a static stretch 30 sec lets the muscle release |

## 2.4 Energy systems — matched to time and fuel

**Simple:** Short and explosive = ATP-PC. A hard set to ~50 sec = glycolysis (burns carbs, makes "the burn"). Anything long and steady = oxidative (burns fat + carbs with oxygen).

```
INTENSITY  HIGH ─────────────────────────────► LOW
DURATION   0────10-15s──────30-50s──────────► minutes/hours
SYSTEM     [ ATP-PC ]  [ Glycolysis ]  [ Oxidative/Aerobic ]
FUEL       phosphagens   carbs           fat + carbs (needs O₂)
```

**Oxidative system's 3 sub-steps:** Aerobic glycolysis → Krebs cycle → Electron transport chain.

## 2.5 Planes of motion & axes

**Simple:** Three imaginary sheets of glass cut the body. Which plane a movement happens in tells you the movement's name.

| Plane | Splits body into | Motions | Axis | Example |
|---|---|---|---|---|
| **Sagittal** | Left / right | Flexion, extension | Coronal (side-to-side) | Bicep curl, squat, walking |
| **Frontal** | Front / back | Abduction, adduction, lateral flexion, eversion/inversion | Anterior-posterior | Side lunge, lateral raise |
| **Transverse** | Top / bottom | Internal/external rotation, horizontal ab/adduction, rotation | Longitudinal (vertical) | Swinging a bat, cable rotation |

**Memory:** **S**agittal = **S**tep forward (flex/extend). Frontal = jumping jacks (out to the side). Transverse = twisting.

## 2.6 The heart & circulation

**Blood flow through the heart** (deoxygenated side then oxygenated side):
```
Body → Right Atrium (no O₂) → Right Ventricle (no O₂) → LUNGS (pick up O₂)
     → Left Atrium (O₂) → Left Ventricle (O₂) → out to the whole body
```
- **Right side = deoxygenated** blood, pumps to lungs.
- **Left side = oxygenated** blood, pumps to body. (Left ventricle is the strongest chamber.)

**Blood functions:** transports oxygen, waste, hormones, and nutrients; carries heat / regulates temperature; clots to protect; fights disease.

## 2.7 Heart rate zones & training intensity

**Estimated max HR = 220 − age.**

| Zone | % of Max HR | Purpose |
|---|---|---|
| **Zone 1** | 65–75% | Base/recovery aerobic |
| **Zone 2** | 76–85% | Aerobic + anaerobic threshold |
| **Zone 3** | 86–95% | High-intensity/power |

- **General health cardio:** ~**60% of max oxygen consumption (VO₂ max)**.
- **Recommendation for adults:** **150 min/week moderate** OR **75 min/week vigorous** aerobic exercise.
- **Measure HR at:** the **radial pulse** (wrist).

## 2.8 The Integrated Flexibility Continuum — matches the OPT levels

**Simple:** Every stretch starts with foam rolling (SMR) first, then a stretch type that matches the client's phase.

| Flexibility type | Pair | Used in OPT phase | Purpose |
|---|---|---|---|
| **Corrective** | SMR + **static** stretching | Phase 1 (Stabilization) | Fix imbalances, lengthen tight muscles |
| **Active** | SMR + **active-isolated** stretching | Phases 2–4 (Strength) | Prep muscles, improve neuromuscular efficiency |
| **Functional** | SMR + **dynamic** stretching | Phase 5 (Power) | Movement-based, sport-ready ROM |

- **SMR (foam rolling)** works via the **GTO** → autogenic inhibition → muscle relaxes.
- **Static stretch:** hold ~30 sec. **Reciprocal inhibition:** contract the opposite muscle to let the target relax.

## 2.9 Postural distortion patterns

**Cumulative injury cycle** (why bad posture snowballs):
```
tissue trauma → inflammation → muscle spasm → adhesions →
altered neuromuscular control → muscle imbalance → (repeat)
```

**The 3 syndromes:**

| Syndrome | Region | Tight (overactive) | Weak (underactive) |
|---|---|---|---|
| **Pronation distortion** | Foot/ankle/knee | Gastroc, soleus, peroneals, adductors, IT band, hip flexors, biceps femoris (short head) | Ant./post. tibialis, vastus medialis, glute med/max, hip external rotators |
| **Lower crossed** | Lumbo-pelvic-hip | Gastroc, soleus, hip flexors, adductors, lats, erector spinae | Ant./post. tibialis, glute max, glute med, transverse abdominis, internal oblique |
| **Upper crossed** | Neck/shoulder | Upper traps, levator scapulae, SCM, scalenes, lats, teres major, subscapularis, pec major/minor | Deep cervical flexors, serratus anterior, rhomboids, mid/lower traps, teres minor, infraspinatus |

## 2.10 The Overhead Squat Assessment (OHSA) — the highest-value assessment on the exam

**What you view:**
- **Anterior (front):** feet, ankles, knees.
- **Lateral (side):** LPHC (lumbo-pelvic-hip complex), shoulders, cervical spine.

**The 5 compensations — memorize which muscles are tight and which are weak.** This is the most heavily drilled table in the Assessment domain:

| Compensation | Tight / Overactive | Weak / Underactive |
|---|---|---|
| **Feet turn out** | Soleus, lateral gastroc, biceps femoris (short head) | Medial gastroc, medial hamstring, gracilis, sartorius, popliteus |
| **Knees move in (valgus)** | Adductor complex, biceps femoris (short), TFL, vastus lateralis | Glute med/max, vastus medialis oblique (VMO) |
| **LPHC leans forward** | Soleus, gastroc, hip flexor complex, abdominal complex | Anterior tibialis, glute max, erector spinae |
| **Low back arches** | Hip flexor complex, erector spinae, lats | Glute max, hamstrings, intrinsic core stabilizers |
| **Arms fall forward** | Lats, teres major, pec major/minor | Mid/lower traps, rhomboids, rotator cuff |

> **Pattern to remember:** In almost every case the **tight muscle pulls the joint out of line, and the weak muscle is the one that should have stopped it.** Knees cave in → adductors (inner thigh) too tight, glutes too weak. Arms fall forward → chest/lats too tight, mid-back too weak.

## 2.11 The core & stabilization systems

**Core = 3 systems:** local stabilization, global stabilization, movement system.

- **Local stabilization system** (Type I, slow-twitch, attach to vertebrae): **transverse abdominis, internal oblique, lumbar multifidus, pelvic floor, diaphragm.** These stabilize the spine, they don't produce big movement.
- **Best core exercise for a beginner:** the **prone iso-ab (plank)** — a drawing-in / bracing stabilization exercise.
- **Core progression:** stabilization (no lower-body movement) → strength (bending at hip/knee, e.g. crunches) → power ("hop"/explosive, e.g. med-ball throws).

## 2.12 Plyometric (reactive) training — 3 phases

```
1. Eccentric (loading)  →  2. Amortization (the pause — SHORTEST time)  →  3. Concentric (unloading/explosion)
```
- **Amortization = the transition/pause.** The **shorter** it is, the more powerful the jump. A long amortization phase = lost power.
- Progression: stabilization (hold the landing ~3–5 sec) → strength (repeated, controlled) → power (as fast as possible).

## 2.13 General Adaptation Syndrome (GAS) — how the body responds to stress

```
1. Alarm reaction  →  2. Resistance development  →  3. Exhaustion
   (shock/response)     (body adapts, gets stronger)   (too much stress → injury/overtraining)
```
This is the "why" behind progressive overload and needing rest.

## 2.14 Resistance training systems

Single set · Multiple set · Pyramid · Superset · Drop set · Circuit training · Peripheral heart action · Split routine · Vertical loading · Horizontal loading.

- **Vertical loading:** move DOWN the workout card (chest → back → legs, one set each) then repeat — keeps HR up, good for circuits.
- **Horizontal loading:** finish ALL sets of one exercise before moving on — classic strength approach.
- **Peripheral heart action:** vertical loading variant alternating upper/lower body.

## 2.15 Nutrition — the numbers you must have

| Item | Value |
|---|---|
| **Protein — calories/gram** | **4 cal/g** |
| **Carbohydrate — calories/gram** | **4 cal/g** |
| **Fat — calories/gram** | **9 cal/g** |
| **Alcohol — calories/gram** | **7 cal/g** |
| **Recommended macro %** | Protein 10–35%, Carbs 45–65%, Fat 20–35% |
| **Protein needs** | Sedentary ~0.4 g/lb; Strength ~0.5–0.8 g/lb; Endurance ~0.5–0.6 g/lb |
| **Amino acids** | 20 total, **9 essential** |
| **Fluid during exercise** | 6–12 oz every 15–20 min; ~16–24 oz per lb lost after |
| **Vitamins toxic in excess** | Zinc, Iron, Vitamin D, Vitamin A (fat-soluble + minerals build up) |

## 2.16 Behavior change & professional practice

- **Stages of change:** Precontemplation → Contemplation → Preparation → Action → Maintenance.
- **SMART goals:** Specific, Measurable, Attainable, Realistic/Relevant, Timely.
- **Barriers to exercise:** not enough time, unrealistic goals, lack of social support, social physique anxiety, convenience.
- **FITTE principle:** Frequency, Intensity, Time, Type, Enjoyment.
- **BMI:** Overweight = 25.0–29.9; Obese = 30.0+ (Class I obese 30.0–34.9).

# PART 4 — COMMON TRICK QUESTIONS & TRAP ALERTS

> **⚠ TRAP 1 — "The muscle spindle relaxes the muscle."**
> No. **Spindle = LENGTH → CONTRACT** (stretch reflex). The **GTO** is the one that RELAXES (senses tension). The exam will swap these. Anchor: sp**IN**dle makes it tighten **IN**; GTO **G**ives **T**ension **O**ff.

> **⚠ TRAP 2 — "SMART's A and R stand for Ambitious and Rigid" / "the M is for Motivating."**
> M = **Measurable**, A = **Attainable**, R = **Realistic/Relevant**. Your cheatsheet said "Immeasurable" — that's a typo; it is **Measurable**.

> **⚠ TRAP 3 — "RQ of 1.0 = 100% fat."**
> Backwards. **RQ 1.0 = 100% carbohydrate. RQ 0.70 = 100% fat.** Higher RQ = more carbs. (Your cheatsheet listed RQ=1 twice — one was meant to be 0.70/fat.)

> **⚠ TRAP 4 — "A deconditioned client with a goal of building muscle should start in Phase 3 (Hypertrophy)."**
> No. **Everyone starts in Phase 1 (Stabilization Endurance)** regardless of goal. You build the foundation first.

> **⚠ TRAP 5 — "Fat has 4 calories per gram like the others."**
> Fat = **9** cal/g (more than double). Protein and carbs = 4, alcohol = 7.

> **⚠ TRAP 6 — "In the overhead squat, if the knees cave in, the glutes are tight."**
> Opposite. Knees caving = **adductors/TFL TIGHT, glutes WEAK.** The weak muscle is the one that failed to hold the joint in place.

> **⚠ TRAP 7 — "Cardio only happens in the endurance phase."**
> Cardiorespiratory training is in **all three OPT levels** (Stage I, II, III).

> **⚠ TRAP 8 — "Wolff's Law is about soft tissue."**
> **Wolff = bone** (osseous). **Davis = soft tissue.** W for the harder tissue.

> **⚠ TRAP 9 — "Phase 4 (Max Strength) uses short rest to keep intensity up."**
> No. Max strength uses the **LONGEST rest, 3–5 minutes** — heavy near-maximal loads need full recovery. Short rest (0–60/90 sec) is for endurance/hypertrophy phases.

> **⚠ TRAP 10 — "A longer amortization phase makes a more powerful jump."**
> Opposite. The amortization (pause) should be **as SHORT as possible** — a long pause wastes the stored elastic energy.

> **⚠ TRAP 11 — "A CPT can design a custom meal plan and recommend supplements to fix a deficiency."**
> Out of scope. CPTs give **general** nutrition guidance (based on public guidelines) only. Meal plans / diagnosing deficiencies = refer to a **registered dietitian / physician.**

> **⚠ TRAP 12 — "Slow-twitch fibers are bigger and produce more force."**
> Backwards. **Fast-twitch (Type II)** are larger, stronger, fatigue fast. Slow-twitch are smaller, endurance, more oxygen.

> **⚠ TRAP 13 — "Abduction happens in the sagittal plane."**
> No. **Abduction/adduction = frontal plane.** Sagittal is flexion/extension. Rotation = transverse.

> **⚠ TRAP 14 — "A client who says 'I've been working out for 8 months' is in the Action stage."**
> Over **6 months** of consistent behavior = **Maintenance**, not Action. Action is the first ~6 months.

> **⚠ TRAP 15 — "Phase 2 is Hypertrophy."**
> Phase 2 = **Strength Endurance** (superset strength + stabilization). Phase 3 = Hypertrophy. Keep the order: 1 Stab-endurance, 2 Strength-endurance, 3 Hypertrophy, 4 Max strength, 5 Power.

> **⚠ TRAP 16 — "The GTO/foam rolling causes the muscle to contract."**
> SMR/foam rolling stimulates the GTO → **relaxation** (autogenic inhibition). That's why you foam roll to release a tight muscle.

> **⚠ TRAP 17 — "Reciprocal inhibition = the target muscle relaxes itself."**
> Reciprocal inhibition = the **opposite (antagonist)** muscle contracts, causing the target to relax. (Autogenic inhibition is the GTO relaxing the same muscle.)

> **⚠ TRAP 18 — "Endomysium is the outermost muscle layer."**
> Endomysium is the **deepest** (wraps individual fibers). Order outside-in: **Epi**mysium → **Peri**mysium → **Endo**mysium.

# PART 5 — MEMORY TOOLS

**OPT phases (1–5) — "Silly Sally Has Many Pals"**
**S**tabilization endurance → **S**trength endurance → **H**ypertrophy → **M**ax strength → **P**ower.

**Reps trend across phases — "the staircase"**
Phase 1 highest reps/lightest (12–20 @ 50–70%), climbing to Phase 4 lowest reps/heaviest (1–5 @ 85–100%). Reps ⬇, load ⬆. Power (5) breaks the pattern: it's TWO exercises, one heavy + one fast-light.

**Spindle vs. GTO**
Muscle **sp-IN-dle** → tighten **IN** (length → contract). **G.T.O.** → **G**ives **T**ension **O**ff (tension → relax).

**Wolff vs. Davis**
**W**olff = "**W**eight-**b**earing bone." Davis = the soft one left over.

**Planes**
**S**agittal = **S**tep (forward/back — flex/extend). **F**rontal = **F**lapping like a jumping jack (out to the side). **T**ransverse = **T**wist.

**Macro calories — "4-4-9, and booze is 7"**
Protein 4, Carbs 4, Fat 9, Alcohol 7.

**Stages of change — "Precisely Contemplate Preparing Action's Maintenance"**
Pre-contemplation, Contemplation, Preparation, Action, Maintenance.

**Energy systems by clock**
0–15 sec = **A**TP-PC (Almost instant). To ~50 sec = **G**lycolysis (Grind/burn, carbs). Minutes+ = **O**xidative (Oxygen, fat).

**Heart flow — "right is wrong (no O₂), left is right (O₂)"**
Right side = deoxygenated → lungs. Left side = oxygenated → body.

**Muscle layers — "Every Person Eats" (outside → in)**
**E**pimysium → **P**erimysium → **E**ndomysium.

**Amortization**
Think of a hot stove: the SHORTER your foot touches the ground, the more explosive. Short amortization = more power.

**Flexibility continuum matches the OPT level**
**C**orrective → static (Phase 1). **A**ctive → active-isolated (2–4). **F**unctional → dynamic (Phase 5). Order = "CAF." Every one starts with foam rolling first.

**FITTE** — **F**requency **I**ntensity **T**ime **T**ype **E**njoyment.

# PART 6 — REAL-WORLD APPLICATIONS

**A brand-new client, sedentary, wants to "get toned."**
→ Start **Phase 1 Stabilization Endurance** regardless of the goal. 12–20 reps, 1–3 sets, 50–70%, slow 4/2/1 tempo, unstable-but-controlled surfaces. Do NOT jump to hypertrophy just because the goal is aesthetic. Build stability and endurance first.

**During the overhead squat, the client's knees cave inward.**
→ Overactive: **adductors, TFL**. Underactive: **glute medius, VMO**. Program: foam-roll + stretch the adductors/TFL, strengthen the glutes (e.g., lateral tube walks). Do NOT stretch the glutes — they're already weak/long.

**Client's arms fall forward in the overhead squat.**
→ Tight **lats and pecs**, weak **mid/lower traps and rotator cuff**. Foam-roll/stretch chest and lats; strengthen the mid-back. This is upper-crossed syndrome showing up dynamically.

**Client says: "I know I should exercise, I'm planning to start next month."**
→ **Preparation** stage (intends to act soon, maybe taking small steps). If they said "I don't see why I'd need to" that's **Precontemplation**. Match your coaching to the stage — don't hand a precontemplator a 5-day program.

**Client asks you to write a meal plan and recommend supplements for a suspected iron deficiency.**
→ **Out of scope.** You may share general public nutrition guidance, but writing individualized meal plans and diagnosing/treating a deficiency belongs to a **registered dietitian / physician**. Refer out.

**Client's goal is a higher vertical jump for basketball.**
→ Eventually **Phase 5 Power** (a heavy strength lift supersetted with an explosive plyometric like a box jump), but only after progressing through stabilization and strength. Coach a **short amortization** on landings.

**You want to keep an overweight client's heart rate elevated and save time.**
→ Use **vertical loading / circuit** (one set of each exercise down the card, minimal rest) and Zone 1–2 cardio (65–85% max HR). Fluids: 6–12 oz every 15–20 min.

**Client fatigues within ~12 seconds of all-out effort, then power drops.**
→ That's the **ATP-PC system** depleting. Program adequate rest (near-full recovery, ~3 min for 100% ATP restoration) for true power/strength work.
